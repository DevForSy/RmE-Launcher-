## Hey everyone this is the first release of RmE Launcher.

I built it because I was tired of opening five different launchers just to play my games. This one pulls everything into a single window and gets out of your way.

Download the exe below and run it. That's it. If Windows throws a SmartScreen warning, click "More info" → "Run anyway" — that just happens because the app isn't signed yet.

A couple of things worth knowing:

Covers for games are pulled from the web (Steam's public store API), so the first launch needs internet. After that they're cached.
Discord status works if you have the desktop app running, and you'll need to enable "Display current activity" in Discord's Activity Privacy settings.
Everything else works completely offline.
If something breaks or a game doesn't show up, let me know.
